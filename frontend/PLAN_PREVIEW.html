Video Platform MVP Plan

유튜브형 영상 플랫폼을 프론트엔드 MVP부터 완성합니다.

처음 목표는 실제 서비스처럼 탐색, 검색, 시청, 채널 확인, 업로드 흐름을 브라우저에서 확인할 수 있는 상태를 만드는 것입니다. 이후 백엔드, DB, 인증, 실제 파일 업로드로 확장합니다.

최종 목표 영상 발견부터 시청, 채널, 업로드까지 이어지는 영상 플랫폼 웹앱
초기 목표 React + TypeScript 기반 화면 MVP와 사용자 흐름 완성
진행 방식 목업 데이터로 빠르게 구현한 뒤 API/DB/인증으로 확장

접근 방식 비교

추천

프론트엔드 MVP 우선

가장 빨리 브라우저에서 결과를 확인하고, 현재 프로젝트 구조를 그대로 활용합니다.

풀스택 우선

처음부터 서버와 DB까지 잡지만 범위가 커져 화면 완성이 늦어질 수 있습니다.

디자인 시스템 우선

장기 일관성은 좋지만 초기 사용자 흐름 검증에는 속도가 느립니다.

주요 화면

홈

추천 영상, 카테고리, 검색, 사이드바

검색

검색어 기반 결과와 빈 상태

영상 상세

플레이어, 댓글, 추천 영상, 채널 정보

채널

배너, 프로필, 구독자, 채널 영상

업로드

메타데이터 입력과 등록 흐름 시뮬레이션

사용 기술

  • React
  • TypeScript
  • Vite
  • React Router
  • CSS
  • lucide-react
  • Mock Data

중간 목표

1

기반 점검

문서 정리, 빌드 확인, 현재 라우트 확인

2

홈 개선

영상 카드, 카테고리, 반응형 그리드 정리

3

상세 개선

플레이어, 댓글, 추천 영상, 채널 영역 강화

4

검색/채널

검색 결과와 채널 페이지 흐름 완성

5

업로드

폼 검증과 등록 시뮬레이션 구현

6

품질 정리

모바일, 접근성, 빈 상태, 오류 상태 점검

7

확장 준비

API, DB, 인증, 파일 저장소 계획 수립

다음 진행

이 계획을 기준으로 먼저 빌드와 현재 화면을 확인한 뒤, 1단계부터 구현을 진행합니다. MVP가 안정되면 백엔드 확장 설계를 별도 문서로 작성합니다.
